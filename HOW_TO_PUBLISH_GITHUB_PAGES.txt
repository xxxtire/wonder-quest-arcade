WONDER QUEST PARTY ARCADE v5.0 — PUBLISHING

IMPORTANT: upload the contents of this project folder, not the ZIP file and not the enclosing folder.

At the repository root, you should see:
  index.html
  css/style.css
  js/data.js
  js/games.js
  js/app.js
  assets/scenes/...
  assets/gallery/...
  assets/audio/...

GitHub Pages steps:
1. Open your repository.
2. Click Add file -> Upload files.
3. Drag in index.html, css/, js/, assets/, .nojekyll, README.md, VERSION.txt, and this guide.
4. Commit changes.
5. Open Settings -> Pages.
6. Source: Deploy from a branch; Branch: main; Folder: /(root); Save.
7. Open https://xxxtire.github.io/wonder-quest-arcade/ and hard-refresh with Ctrl+F5 if a cached version appears.

Offline USB steps:
1. Extract the whole ZIP into one folder.
2. Do not separate or rename css/, js/ or assets/.
3. Double-click index.html in current Chrome/Edge. Audio begins after first user interaction if the browser blocks autoplay.
