# Changelog — Wonder Quest Party Arcade

## v5.0 — Party Arcade
- Rebuilt the experience around pure arcade play instead of a question-and-answer catalogue.
- Added 32 touch-first games covering tap reflex, swipe slicing, paddle/ball physics, shooter, runner, catcher, stack timing, match-3, ball sorting, sliding-car escape, generated maze, memory flip, sequence, cannon aiming, hockey, penalty shootout, fishing, bubble shooter, treasure digging, flood-fill, frog swapping, rhythm timing, boss dodging, pinball, traffic control and free drawing.
- Added randomized obstacles and targets, combo text, particles, score/time/lives HUD, local best scores, team star scores and five-round party mode.
- Split the source into HTML, CSS, data and game-engine JavaScript files for easier maintenance.
- Bundled local scene art, world gallery art, sound effects and background music; no remote scripts, APIs or CDN assets are used.
- Added GitHub Pages and USB offline instructions.
